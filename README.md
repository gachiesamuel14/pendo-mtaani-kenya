# Pendo Mtaani — Kenya Location-Based Dating

Connect with people near you across Kenya. County matching, GPS, swipe, chat demo.

## Features (MVP)
- Profile cards with Kenyan context (counties, interests)
- Browser geolocation
- Mock nearby matches
- Filters by county, age, interests
- Responsive design

## Deploy
Push to GitHub → connect to Netlify for continuous deployment.

Live demo coming soon on Netlify.
